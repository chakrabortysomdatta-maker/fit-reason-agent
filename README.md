# Fit-Reason Agent

Internal pilot for Dhaga & Co. Reads every return reason and support ticket (English, Hindi, Hinglish) and sends what it finds to the person who can act on it:

- **Priority queue** for Neha (Category Head): grouped issues, worst first.
- **Guidance review** for Ms Chhaya Gupta (CX reviewer): suggested replies in the customer's language, rated in shadow mode. Nothing is sent to customers.
- **Delay scorecard** for Neha: late orders blamed on vendor (stock wait), warehouse or courier (transit).
